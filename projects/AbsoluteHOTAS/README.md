# AbsoluteHOTAS — Core SFSE Plugin

This directory contains the core SFSE plugin source for AbsoluteHOTAS: direct HID input, flight control injection, in-game binding wizard, and ship action output.

## Requirements

- Starfield 1.16.242 or later
- SFSE 0.2.20 or later

No additional runtime dependencies (Address Library, vJoy, Joystick Gremlin, etc.) are required.

## Documentation

See the [root README](../../README.md) for full user-facing documentation, including:

- Installation and quick start
- In-game binding wizard guide
- Multi-zone throttle calibration
- Dual-stick / HOSAS accumulator mode
- HOSAM mode (stick + mouse)
- Aiming configuration
- Ship action bindings and custom button expansion
- INI reference and troubleshooting
